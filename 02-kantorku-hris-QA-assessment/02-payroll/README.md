# Payroll Analysis

## Overview

This section contains my analysis of selected Payroll workflows in an HRIS application.

## Scope

The analysis covers:

1. Run Payroll
2. Adjust Attendance Per Employee
3. Adjust Benefit Per Employee

## Analysis Objectives

The objectives were to understand:

* The business process
* User actions
* System responses
* API communication

## Deliverables

* Payroll BPMN
* API Endpoint Analysis
* API Contracts

## Note

Sensitive payroll information, employee information, production credentials, and authentication data have been excluded from this portfolio.
