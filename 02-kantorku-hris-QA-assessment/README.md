# KantorKu HRIS – QA Technical Assessment

## Overview

This repository contains my work from a QA technical assessment for a QA Internship application.

The assessment focused on analyzing an HRIS application, understanding its business processes, inspecting API communication, creating test data through automation, and identifying usability improvements.

## Assessment Tasks

### 1. Employee Onboarding

Analyze and design the proposed **Employee Onboarding** feature.

Deliverables:

* System Flow using BPMN
* List of API Endpoints
* API Contracts
* Non-Functional Requirements
* User/Test Matrix
* Monitoring Matrix
* Task List and Effort Estimation
* HTML, CSS, and JavaScript Mockup


---

### 2. Payroll

Analyze the existing **Payroll → Run Payroll** feature.

The analysis covers:

* Run Payroll
* Adjust Attendance Per Employee
* Adjust Benefit Per Employee
* Adding and testing with different users

Deliverables:

* System Flow using BPMN
* List of API Endpoints
* API Contracts


---

### 3. Test Data Automation

Create test/master data automatically for **General Settings → Company Division → Company Unit**.

The automation covers:

* Add 10 new Positions
* Add Company Unit named "Area"
* Add 20 Areas
* Add Company Unit named "Sub Area"
* Add 20 Sub Areas

The script is designed to:

* Handle authentication using a login flow or user token
* Create the required data automatically
* Generate test data programmatically

After testing, the created data should be deleted manually to restore the system to its previous state.


---

### 4. UX / Product Analysis

Explore the HRIS application and identify the feature that is hardest to understand.

The analysis covers:

* The feature identified as difficult
* Why the feature is difficult to understand
* Suggestions for improvement
* Estimated effort required for the improvement
