# Mobile-Based Attendance Information System

## 1. Project Overview
Sistem Presensi berbasis mobile yang menggunakan teknologi Location-Based Service merupakan sistem yang dikembangkan yang digunakan untuk membantu dalam proses pencatatan kehadiran peserta kegiatan dengan memvalidasi lokasi realtime peserta. Sistem ini juga dapat membantu pengelolaaan data jadwal kegiatan dan data  kehadiran peserta yang lebih mudah dan efisien. sistem ini mempunyai dua aktor utama yaitu:
- Admin
- Participant
  
## 2. Background
Pencatatan kehadiran sebelumnya dilakukan secara manual sehingga menimbulkan kendala antara lain:
- Buku kehadiran sering hilang.
- Data kehadiran harus direkap kembali.
- Sering terjadi kecurangan.
- Risiko terjadinya kesalahan pencatatan.
Dari permasalahan tersebut maka dikembangan sistem presensi berbasis mobile yang mendigitalisasi proses kehadiran.

## 3. Objectives
Tujuan sistem:
- Mendigitalisasi proses pencatatan kehadiran.
- Mempermudah peserta melakukan presensi.
- Membantu admin mengelola data kehadiran.
- Menyediakan validasi lokasi.
- Menyediakan riwayat kehadiran.
- Membantu proses monitoring dan pelaporan.

## 4. User Roles
Admin:
- Login
- Pengelolaan jadwal.
- Pengelolaan presensi.
- Pengelolaan pengajuan izin.
- Melihat rekapitulasi data kehadiran.
- Logout
Participant:
- Registrasi.
- Login.
- Melihat jadwal.
- Melakukan presensi.
- Melihat riwayat presensi.
- Mengajukan izin.
- Melihat riwayat izin.
- Mengubah Profil.
- Logout
