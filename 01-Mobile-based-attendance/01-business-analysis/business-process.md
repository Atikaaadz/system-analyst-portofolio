# Business Process
## Existing Process
Peserta datang ke lokasi → Peserta mengisi buku hadir → kegiatan berlangsung → Admin melakukan rekap → Laporan kehadiran

## Proposed Process

Admin mengelola jadwal → Peserta melihat jadwal → Peserta melakukan presensi → Sistem memvalidasi lokasi → Sistem menyimpan presensi → Peserta melihat riwayat kehadiran → Admin melihat data kehadiran
