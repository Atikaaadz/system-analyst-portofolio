# User Stories
|ID|Feature|User Story|
|---|---|---|
| US-01 | Registrasi| Sebagai Participant, saya ingin membuat akun agar dapat menggunakan sistem presensi.|
| US-02 | Login| Sebagai Admin/Participant, saya ingin melakukan login agar dapat mengakses fitur sesuai akun saya.|
| US-03 | Logout| Sebagai Admin/Participant, saya ingin melakukan logout agar dapat mengakhiri sesi dengan aman.|
| US-04 | Kelola Profil| Sebagai Participant, saya ingin mengelola profil agar informasi akun saya tetap sesuai. |
| US-05 | Lihat Jadwal| Sebagai Participant, saya ingin melihat jadwal kegiatan agar mengetahui waktu pelaksanaan kegiatan.|
| US-06 | Presensi| Sebagai Participant, saya ingin melakukan presensi agar kehadiran saya tercatat.|
| US-07 | Riwayat Presensi dan izin| Sebagai Participant, saya ingin melihat riwayat kehadiran agar dapat mengetahui catatan presensi saya.|
| US-08 | Ajukan Izin| Sebagai Participant, saya ingin mengajukan izin agar ketidakhadiran saya dapat dicatat.|
| US-09 | Kelola Jadwal| Sebagai Admin, saya ingin mengelola jadwal agar informasi kegiatan dapat tersedia bagi Participant.|
| US-10 | Kelola Data Kehadiran| Sebagai Admin, saya ingin melihat dan mengelola data kehadiran agar dapat memantau presensi Participant.|
| US-11 | Laporan Kehadiran| Sebagai Admin, saya ingin melihat rekapitulasi kehadiran agar dapat memperoleh informasi kehadiran peserta.|
| US-12 | Kelola Pengajuan Izin | Sebagai Admin, saya ingin melihat rekapitulasi kehadiran agar dapat memperoleh informasi kehadiran peserta.|
