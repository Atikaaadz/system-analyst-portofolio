# Functional Requiremements
| ID | Functional Requirement | Actor | Description | Status |
|---|---|---|---|---|
|FR01|Registrasi|Participant|Sistem memungkinkan participant membuat akun|
|FR02|Login|Participant & Admin |Sistem memungkinkan pengguna masuk menggunakan akun yang terdaftar|
|FR03|Logout|Participant & Admin|Sistem memungkinkan pengguna mengakhiri sesi|
|FR04|Kelola Profil|Participant|Sistem memungkinkan participant mengupdate profil|
|FR05|Kelola Jadwal|Admin|Sistem memungkinkan Admin mengelola jadwal kegiatan|
|FR06|Lihat Jadwal|Participant| Sistem memungkinkan participant melihat jadwal kegiatan|
|FR07|Presensi|Participant| Sistem memungkinkan participant melakukan presensi dengan validasi lokasi|
|FR08|Ajukan Izin|Participant|Sistem memungkinkan participant dapat mengajukan izin|
|FR09|Lihat Riwayat|Participant|Sistem memungkinkan participant melihat riwayat kehadiran dan pengajuan izin|
|FR10|Kelola Data Kehadiran|Admin|Sistem memungkinkan Admin melihat  dan mengelola status pada data kehadiran|
|FR11|Kelola Pengajuan Izin|Admin|Sistem memungkinkan Admin mengelola status pengajuan izin participant|
|FR12|Laporan Kehadiran|Admin|Sistem memungkinkan admin melihat rekap data kehadiran|
